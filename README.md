# PLATWFC — 3D Platformer

Игровой клиент PLATWFC на Three.js и realtime-сервер комнат. На Windows сервер запускается двойным щелчком по BAT-файлу. Docker, PowerShell и GitHub Desktop не нужны.

## Получить проект

Открой репозиторий:
https://github.com/voloda06346/platwfc-2-5d-platformer

Нажми **Code → Download ZIP**, распакуй проект в обычную папку Windows. Это первоначальная загрузка; дальше файлы можно обновлять автоматическим BAT-обновлятором.

## Требования для Windows

- Windows 10 или 11;
- Node.js 20 или новее (установщик включает npm);
- доступ к интернету для первой установки зависимостей и загрузки Three.js с CDN.

## Запуск игры и локального сервера

1. Открой папку проекта.
2. Дважды щёлкни `START-PLATWFC.bat`.
3. При первом запуске BAT установит серверную зависимость `ws`.
4. Оставь окно сервера открытым.
5. Открой игру в браузере: http://localhost:8080/

Сервер отдаёт локальные файлы игры и WebSocket на одном адресе. 3D-клиент автоматически подключается к `ws://localhost:8080/ws`, когда открыт с localhost.

Проверка состояния сервера: http://localhost:8080/health

Для остановки сервера нажми `Ctrl+C` в окне BAT.

## Управление

- `W A S D` или стрелки — движение относительно камеры;
- `Space` — прыжок;
- кнопка `♫ TWIN SLOP` — включает/выключает оригинальный короткий фонк-cowbell эффект при каждом прыжке (по умолчанию включён);
- кнопка `🤖 БОТЫ` — включает/выключает трёх локальных AI-компаньонов;
- `F`, клик по стене или кнопка `X` геймпада — обрушить стену, на которую навёлся курсор-помощник;
- правый стик геймпада или мышь — управление курсором-помощником; левый стик — движение; `A` — прыжок; `RT` — спринт;
- кнопка `◎ CURSOR` — показать/скрыть курсор-помощник;
- `Shift` — спринт;
- `Shift + Space` во время быстрого бега — длинный прыжок;
- `E` в воздухе — бросок вперёд;
- `Q` в воздухе — удар вниз;
- `R` на земле во время движения — кувырок;
- кнопка `♫ МУЗЫКА` — включить/выключить оригинальный процедурный саундтрек (браузер запускает звук только после нажатия);
- поле «Твой ник» и кнопка «Применить» — смена имени над персонажем;
- удерживай левую кнопку мыши и двигай мышь по игровому окну — вращение камеры;
- на узких экранах доступны сенсорные кнопки.

Персонаж использует оригинальный округлый скелетный риг на THREE.Bone с плавным смешиванием поз, выразительным бегом/спринтом, прыжком с поднятыми руками, длинным прыжком, воздушным броском, ударом вниз и кувырком. При отрыве от платформы есть лёгкое растяжение, а при приземлении — squash-and-stretch с быстрым восстановлением. PLATWFC Audio создаёт собственный синтезированный саундтрек через Web Audio API; он не содержит аудио из других игр. Никнеймы отображаются над головами игроков как читаемые billboard-метки и синхронизируются вместе с состояниями игроков. Движение использует плавное ускорение, инерцию и поворот персонажа с интерполяцией. В мире есть платформы, прыжки и собираемые монеты. Три автономных бота-компаньона перемещаются по основному маршруту, сами рассчитывают момент прыжка между островами и разворачиваются на концах трассы. Эти боты локальные для каждого клиента и не занимают сетевые слоты мультиплеера. На маршруте размещены интерактивные стены: курсор-помощник наводится мышью или правым стиком стандартного геймпада, подсвечивает стену и позволяет опрокинуть её кнопкой F, кликом или кнопкой X. Левый стик и крестовина геймпада управляют движением, A прыгает, RT или RB ускоряет бег. На сенсорных экранах есть кнопка PUSH.

## Обновить проект без GitHub Desktop и PowerShell

Если старый обновлятор уже выдаёт ошибку, скачай [REPAIR-PLATWFC-UPDATER.bat](https://raw.githubusercontent.com/voloda06346/platwfc-2-5d-platformer/main/REPAIR-PLATWFC-UPDATER.bat), сохрани его в папку проекта рядом с `START-PLATWFC.bat` и запусти двойным щелчком. Он скачает исправленный обновлятор, заменит старый и сразу запустит обновление.

Для обычных будущих обновлений:

1. Останови сервер через `Ctrl+C`.
2. Дважды щёлкни `UPDATE-PLATWFC.bat`.
3. После завершения запусти `START-PLATWFC.bat` и обнови страницу игры через `Ctrl+F5`.

Обновлятор загружает ZIP с GitHub, проверяет его, распаковывает и копирует файлы. Он сохраняет локальные `.env`, `node_modules`, `.git` и сам BAT-файл, который сейчас выполняется. Если файл обновлятора отсутствует, его можно скачать отдельно: [UPDATE-PLATWFC.bat](https://raw.githubusercontent.com/voloda06346/platwfc-2-5d-platformer/main/UPDATE-PLATWFC.bat).

## PLATWFC Workshop и DLC

При запуске Node.js-сервера автоматически создаётся папка `dlc-workshop` в корне проекта.

1. Нажми **✦ WORKSHOP** в игре.
2. Установи один из рекомендуемых паков или нажми **УСТАНОВИТЬ STARTER PACK**.
3. Свои дополнения можно импортировать кнопкой **ИМПОРТИРОВАТЬ JSON**.
4. Также можно вручную скопировать корректный JSON-файл в `dlc-workshop` и нажать **ОБНОВИТЬ** в Workshop.

Поддерживаются безопасные типы дополнений:
- `level` — новые платформы (до 24 платформ в одном паке);
- `cosmetic` — цвета одежды и акцентов персонажа;
- `music` — одна из встроенных оригинальных процедурных музыкальных тем.

Примеры JSON находятся в папке `workshop-examples`. Их можно копировать, редактировать и импортировать в игре.

Для безопасности Workshop принимает только JSON-манифесты размером до 64 КБ. Исполняемые JavaScript-файлы и произвольный код не запускаются. Папка `dlc-workshop` хранит установленные паки локально; чтобы поделиться своим дополнением, отправь его JSON-файл другим игрокам.

Мастерская доступна в локальной версии, запущенной через `START-PLATWFC.bat`. GitHub Pages сам по себе не может записывать DLC на диск твоего компьютера.

## Мультиплеер

Локально открытая игра автоматически подключается к WebSocket-серверу на том же компьютере. Игроки входят в комнату `lobby` по умолчанию. Адрес сервера, ник и комната могут быть заданы параметрами URL:

```text
?server=wss://YOUR-HOST/ws&name=Player&room=lobby
```

Комнаты рассчитаны максимум на 16 игроков. Сейчас сервер передаёт позиции игроков; регистрация аккаунтов, хранение паролей и серверные ранги ещё не реализованы.

## Публичный доступ

Локальная проверка на `localhost` не делает сервер доступным друзьям в интернете. Для этого нужен защищённый публичный WSS-адрес и безопасно настроенный туннель или домен. Не публикуй домашний IP, содержимое `.env` или логи. Не открывай домашний компьютер в интернет без согласования с родителем/взрослым, который отвечает за сеть.

## Протокол v1

- `join` — вход в комнату;
- `state` — обновление координат игрока;
- `peer-joined`, `peer-state`, `peer-left` — события других игроков;
- `/health` — JSON-статус сервера.
