# PLATWFC — 2.5D Platformer

Игровой клиент и realtime-сервер PLATWFC. **Docker и PowerShell не требуются для запуска.** На Windows сервер запускается двойным щелчком по BAT-файлу.

## Получить проект без ZIP

1. Установи [GitHub Desktop](https://desktop.github.com/).
2. Открой GitHub Desktop и выбери **File → Clone repository**.
3. Открой вкладку **URL** и вставь:
   `https://github.com/voloda06346/platwfc-2-5d-platformer.git`
4. Выбери папку, куда сохранить проект, и нажми **Clone**.

Так GitHub Desktop скачает рабочую копию репозитория напрямую — ZIP вручную скачивать и распаковывать не нужно. Чтобы получить новые изменения позже, нажимай **Fetch origin**, затем **Pull origin** (если GitHub Desktop предлагает Pull).

## Требования для Windows

- Windows 10 или 11;
- [Node.js 20 или новее](https://nodejs.org/) (установщик включает npm).

## Запуск локального сервера

Открой папку проекта, которую создал GitHub Desktop, и дважды щёлкни:

`START-PLATWFC.bat`

При первом запуске окно само выполнит `npm install`, затем запустит PLATWFC. При последующих запусках установка повторно не нужна, пока зависимости не менялись.

Проверка в браузере: http://localhost:8080/health

WebSocket для локальной разработки: `ws://localhost:8080/ws`.

**Не закрывай окно BAT, пока сервер нужен.** Для остановки нажми `Ctrl+C` в окне сервера.

## Публичный сервер Windows

Публичный запуск также имеет BAT-файл, но требует домен, доступный из интернета компьютер/сервер и Caddy для HTTPS/WSS.

1. Установи обычный Windows `caddy.exe` по инструкции: https://caddyserver.com/docs/install. Положи файл в `tools\caddy.exe` в папке проекта либо добавь Caddy в PATH.
2. Дважды щёлкни `START-PUBLIC-PLATWFC.bat`. При первом запуске он создаст `.env` из шаблона и откроет его в Блокноте.
3. В `.env` укажи свой домен и контактный email, сохрани файл.
4. Дважды щёлкни `START-PUBLIC-PLATWFC.bat` ещё раз.

Публичный WebSocket адрес будет `wss://ТВОЙ-ДОМЕН/ws`. Caddy получает TLS-сертификат автоматически, когда DNS домена и сетевые настройки сделаны правильно.

Для публичного доступа домен должен указывать на сервер, а входящие TCP-порты **80 и 443** должны быть доступны снаружи. На домашнем интернете это может зависеть от роутера и провайдера. Компьютер должен оставаться включённым. Не публикуй домашний IP, содержимое `.env` или логи. Не открывай доступ к домашнему компьютеру в интернет без согласования с родителем/взрослым, который отвечает за сеть.

При публичном запуске открываются два окна: окно Node.js-сервера и окно Caddy. Оставь оба работающими. Чтобы остановить, нажми `Ctrl+C` в обоих окнах.

## Игровой клиент

Клиент публикуется через GitHub Pages. В репозитории открой **Settings → Pages → Build and deployment → Source: GitHub Actions**. Управление: WASD / стрелки, пробел — прыжок.

После публикации клиента подключайся к серверу через адрес вида:

```text
https://voloda06346.github.io/platwfc-2-5d-platformer/?server=wss://ТВОЙ-ДОМЕН/ws&name=Player&room=lobby
```

## Обновление проекта

В GitHub Desktop нажми **Fetch origin**, затем **Pull origin**. После обновления снова запусти нужный BAT-файл. Если сервер уже работает, сначала останови его через `Ctrl+C`.

## Протокол v1

- `join` — вход в комнату (до 16 игроков).
- `state` — обновление позиции игрока.
- `peer-joined`, `peer-state`, `peer-left` — события других игроков.
- `/health` — JSON-статус сервера.

**Текущий статус:** PLATWFC синхронизирует комнаты и позиции. Регистрация аккаунтов, безопасное хранение паролей и серверные ранги (включая `CREATOR`) ещё не реализованы. Ранг создателя будет назначаться серверной настройкой/первичной настройкой аккаунта, а не только по IP.
