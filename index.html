СВОЁ ДОПОЛНЕНИЕ

Импортируй JSON-пак PLATWFC. Сервер проверит его и сохранит в папку dlc-workshop рядом с игрой.

Формат собственного дополнения 
{
  "id": "my-first-island",
  "name": "My First Island",
  "author": "Player",
  "version": "1.0.0",
  "description": "A small new island",
  "type": "level",
  "platforms": [
    {
      "x": -22, "z": -56,
      "width": 5, "depth": 5,
      "height": 5, "color": "#72d7a0"
    }
  ]
}

Поддерживаются типы level, cosmetic и music. Скрипты и исполняемый код в DLC не принимаются.

Локальная мастерская доступна при запуске через START-PLATWFC.bat. Пакеты сохраняются только на этом компьютере.
